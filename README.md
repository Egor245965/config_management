# Эмулятор командной оболочки

Практическая работа по дисциплине «Конфигурационное управление».

Вариант №7.

На данный момент реализованы:

- Этап 1 — REPL;
- Этап 2 — Конфигурация.

Программа представляет собой эмулятор командной оболочки
UNIX-подобной операционной системы.

## Описание

Эмулятор работает в режиме REPL:

1. получает команду пользователя;
2. разбирает введённую строку;
3. определяет команду и её аргументы;
4. выполняет соответствующее действие;
5. выводит результат;
6. снова ожидает ввод пользователя.

Для разбора командной строки используется модуль `shlex`, благодаря чему
поддерживаются аргументы, заключённые в кавычки.

Например:

```text
cd "My Documents"
```

будет разобрано как:

```text
command = cd
args = ["My Documents"]
```

## Этап 1 — REPL

На первом этапе реализованы:

- консольный интерфейс;
- приглашение командной строки на основе данных реальной ОС;
- получение имени пользователя;
- получение имени компьютера;
- разбор команд и аргументов;
- поддержка аргументов в кавычках;
- обработка пустого ввода;
- обработка некорректных кавычек;
- обработка неизвестных команд;
- проверка количества аргументов;
- команда-заглушка `ls`;
- команда-заглушка `cd`;
- команда `exit`;
- модульные тесты.

Команды `ls` и `cd` на данном этапе являются заглушками и пока не
работают с виртуальной файловой системой.

## Поддерживаемые команды

### `ls`

На данном этапе команда является заглушкой.

Пример:

```text
ls
```

или:

```text
ls home documents
```

Эмулятор выводит название команды и переданные аргументы.

### `cd`

На данном этапе команда является заглушкой.

Пример:

```text
cd home
```

Поддерживаются аргументы с пробелами:

```text
cd "My Documents"
```

Команда принимает не более одного аргумента.

При вводе:

```text
cd home documents
```

выводится сообщение:

```text
Ошибка: cd принимает не более одного аргумента
```

### `exit`

Завершает работу эмулятора.

```text
exit
```

Команда не принимает аргументы.

Например:

```text
exit abc
```

Результат:

```text
Ошибка: exit не принимает аргументы
```

После ошибки работа эмулятора продолжается.

## Обработка ошибок

Неизвестная команда:

```text
abracadabra
```

Результат:

```text
Ошибка: неизвестная команда 'abracadabra'
```

Некорректное количество аргументов:

```text
cd home documents
```

Результат:

```text
Ошибка: cd принимает не более одного аргумента
```

Некорректная команда `exit`:

```text
exit abc
```

Результат:

```text
Ошибка: exit не принимает аргументы
```

Незакрытые кавычки:

```text
cd "My Documents
```

Результат:

```text
Ошибка: некорректные кавычки
```

После возникновения ошибки эмулятор продолжает работу.

## Приглашение командной строки

Приглашение формируется на основе данных реальной операционной системы:

```text
username@hostname:~$
```

Для получения имени пользователя используется:

```python
getpass.getuser()
```

Для получения имени компьютера используется:

```python
socket.gethostname()
```

## Этап 2 — Конфигурация

На втором этапе добавлена возможность настройки эмулятора с помощью
параметров командной строки.

Поддерживаются параметры:

- `--vfs` — путь к физическому расположению VFS;
- `--script` — путь к стартовому скрипту.

Пример запуска:

```text
python src\emulator.py --vfs vfs.zip --script startup.txt
```

При запуске выводятся заданные параметры:

```text
Параметры эмулятора:
VFS: vfs.zip
Стартовый скрипт: startup.txt
```

На данном этапе путь к VFS только принимается как параметр.
Непосредственная работа с виртуальной файловой системой будет
реализована на следующем этапе.

## Стартовый скрипт

Стартовый скрипт позволяет автоматически выполнить последовательность
команд при запуске эмулятора.

Пример файла `startup.txt`:

```text
# Проверка стартового скрипта

ls
cd home
cd "My Documents"

# Проверка обработки ошибок

abracadabra
cd home documents
cd "Broken
```

Строки, начинающиеся с `#`, являются комментариями и не выполняются.

Пустые строки также пропускаются.

Во время выполнения стартового скрипта на экран выводятся как команды,
так и результаты их выполнения.

Пример:

```text
admin@DESKTOP:~$ ls
ls []

admin@DESKTOP:~$ cd home
cd ['home']

admin@DESKTOP:~$ cd "My Documents"
cd ['My Documents']
```

Если в стартовом скрипте встречается ошибочная команда, выводится
соответствующее сообщение об ошибке.

Если файл стартового скрипта не найден, программа выводит сообщение
об ошибке без аварийного завершения.

Например:

```text
Ошибка стартового скрипта: [Errno 2] No such file or directory
```

После выполнения стартового скрипта эмулятор переходит в обычный
интерактивный режим.

## Основные функции

### `get_prompt()`

Формирует приглашение командной строки с использованием имени
пользователя и имени компьютера.

### `parse_arguments()`

Обрабатывает параметры командной строки:

- путь к VFS;
- путь к стартовому скрипту.

### `parse_command()`

Разбирает введённую строку на команду и список аргументов.

Для разбора используется `shlex.split()`.

### `execute_command()`

Обрабатывает команды:

- `ls`;
- `cd`;
- `exit`.

Также сообщает об неизвестных командах и неправильных аргументах.

### `run_startup_script()`

Открывает стартовый скрипт, читает его построчно и выполняет команды.

Поддерживает:

- пустые строки;
- комментарии;
- команды с аргументами;
- обработку ошибок.

### `main()`

Основная функция программы.

Выполняет:

- чтение параметров запуска;
- вывод конфигурации;
- запуск стартового скрипта;
- запуск интерактивного REPL.
