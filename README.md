# Эмулятор командной оболочки

Практическая работа по дисциплине «Конфигурационное управление».

Вариант №7.

## Этап 1. REPL

Реализован консольный эмулятор командной оболочки.

Поддерживается:
- приглашение вида `username@hostname:~$`;
- обработка аргументов в кавычках;
- команды-заглушки `ls` и `cd`;
- команда `exit`;
- обработка неизвестных команд;
- обработка неверных аргументов.

## Запуск

```bash
python src/emulator.py
