# Эмулятор командной оболочки

Практическая работа по дисциплине «Конфигурационное управление».

Вариант №7.

На данный момент реализован **Этап 1 — REPL** эмулятора командной
оболочки UNIX-подобной операционной системы.

## Описание

Программа представляет собой прототип командной оболочки.

Эмулятор работает в режиме REPL:

1. получает команду пользователя;
2. разбирает введённую строку;
3. определяет команду и её аргументы;
4. выполняет соответствующее действие;
5. выводит результат;
6. снова ожидает ввод пользователя.

Для разбора командной строки используется модуль `shlex`, благодаря чему
поддерживаются аргументы, заключённые в кавычки.

Например:

```text
cd "My Documents"
```

будет разобрано как:

```text
command = cd
args = ["My Documents"]
```

## Реализованные возможности

На Этапе 1 реализованы:

- интерфейс командной строки;
- приглашение командной строки с использованием данных реальной ОС;
- получение имени пользователя;
- получение имени компьютера;
- разбор команд и аргументов;
- поддержка аргументов в кавычках;
- обработка пустого ввода;
- обработка некорректных кавычек;
- обработка неизвестных команд;
- проверка неправильного количества аргументов;
- команда-заглушка `ls`;
- команда-заглушка `cd`;
- команда `exit`;
- автоматические модульные тесты.

Команды `ls` и `cd` на данном этапе являются заглушками и пока не
работают с виртуальной файловой системой.

## Поддерживаемые команды

### `ls`

На Этапе 1 команда является заглушкой.

Пример:

```text
ls
```

или:

```text
ls home documents
```

Эмулятор выводит название команды и переданные аргументы.

### `cd`

На Этапе 1 команда является заглушкой.

Пример:

```text
cd home
```

Поддерживаются аргументы с пробелами:

```text
cd "My Documents"
```

Команда принимает не более одного аргумента.

При передаче нескольких аргументов:

```text
cd home documents
```

выводится сообщение об ошибке.

### `exit`

Завершает работу эмулятора.

```text
exit
```

Команда не принимает аргументы.

Например:

```text
exit abc
```

не завершит программу, а выведет сообщение об ошибке.

## Обработка ошибок

В программе предусмотрена обработка следующих ситуаций.

Неизвестная команда:

```text
abracadabra
```

Результат:

```text
Ошибка: неизвестная команда 'abracadabra'
```

Слишком много аргументов для `cd`:

```text
cd home documents
```

Результат:

```text
Ошибка: cd принимает не более одного аргумента
```

Аргумент у команды `exit`:

```text
exit abc
```

Результат:

```text
Ошибка: exit не принимает аргументы
```

Незакрытые кавычки:

```text
cd "My Documents
```

Результат:

```text
Ошибка: некорректные кавычки
```

После возникновения ошибки эмулятор продолжает работу.

## Приглашение командной строки

Приглашение формируется на основе данных реальной операционной системы:

```text
username@hostname:~$
```

Для получения имени пользователя используется:

```python
getpass.getuser()
```

Для получения имени компьютера:

```python
socket.gethostname()
```

## Структура проекта

```text
config_management/
├── src/
│   ├── __init__.py
│   └── emulator.py
├── tests/
│   └── test_emulator.py
├── .gitignore
├── README.md
├── run.bat
└── run_tests.bat
```

### `src/emulator.py`

Основной файл программы.

Содержит функции:

- `get_prompt()` — формирование приглашения командной строки;
- `parse_command()` — разбор введённой команды;
- `execute_command()` — обработка команды;
- `main()` — основной цикл REPL.

### `tests/test_emulator.py`

Содержит модульные тесты для проверки основных функций программы.

### `run.bat`

Запускает эмулятор.

### `run_tests.bat`

Запускает автоматические тесты.

## Требования

- `getpass`;
- `shlex`;

Дополнительные библиотеки устанавливать не требуется.

## Запуск программы

Из корневой директории проекта:

```text
run.bat
```

```text
python src\emulator.py
```

## Пример работы

```text
admin@DESKTOP:~$ ls
ls []

admin@DESKTOP:~$ cd home
cd ['home']

admin@DESKTOP:~$ cd "My Documents"
cd ['My Documents']

admin@DESKTOP:~$ cd home documents
Ошибка: cd принимает не более одного аргумента

admin@DESKTOP:~$ hello
Ошибка: неизвестная команда 'hello'

admin@DESKTOP:~$ exit abc
Ошибка: exit не принимает аргументы

admin@DESKTOP:~$ exit
```

Имя пользователя и компьютера в приглашении зависит от системы,
на которой запускается эмулятор.

## Тестирование

Для запуска всех автоматических тестов:

```text
run_tests.bat
```

Также тесты можно запустить командой:

```text
python -m unittest discover -s tests -v
```

Тесты проверяют:

- разбор команды `ls`;
- разбор аргументов;
- аргументы в кавычках;
- несколько аргументов;
- некорректные кавычки;
- корректную работу `exit`;
- ошибку при передаче аргумента в `exit`;
- ошибку при передаче нескольких аргументов в `cd`;
- обработку неизвестной команды.
